one sentence: A game where penguins throw snowballs at eachother.

**live demo:** (https://spaniker.itch.io/penguin-game)
**built by:** Syona Paniker (@spaniker), Ada Xu (@826284-hue)

## how do you use it?

Use WASD and E to throw, to control Penguin 1
Use Arrow keys and SPACE to control Pengion 2
…

## how we built it

We built this using godot with the help of tutororials on Youtube and at the Hack Club Snowglobe Hackathon.

## run it yourself

1. clone the repo
2. install godot
3. press run!
   
## what was hard, and how we fixed it
This was our first time using godot, so we started from the very basics. It was hard to get the snowballs to respawn and effectively detect when a penguin was hit.
